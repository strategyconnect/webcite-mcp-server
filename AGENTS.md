# SDK delivery

Use `scripts/merge-reviewed-pr.sh <PR number> <reviewed full head SHA>` for merges. Do not call `gh pr merge` directly. The wrapper verifies the live PR head, checks the guide against the explicit base/head contracts, posts `webcite-guide-current` success only after that check, and pins the merge to the reviewed commit. It also requires an APPROVE verdict record for the exact head in the shared review ledger (`~/.agents/bin/review-gate`); the gate is a guardrail for cooperating agents. Every bypass path needs `REVIEW_GATE_BYPASS=<reason>` and appends a `gate-bypass` record to the shared ledger: a missing gate binary, or a `REVIEW_GATE` override in place of the default gate. Calling `gh pr merge` directly is outside the gate and is not allowed by repo rules. GitHub main requires the strict `webcite-guide-current` status check, including administrators. This was verified through the branch-protection API on 2026-10-01. The wrapper supplies the check after validating the reviewed commits; no GitHub Actions workflow is used.
