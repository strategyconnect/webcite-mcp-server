## Notes

- Successful no-match query returns `status: 'refuse'` / empty refs with HTTP 200.
- Unknown MCP tool / malformed envelope → protocol error; API/business failures → `isError: true`.
- `private_gold_denied: true` is intentional for A_EVAL_CATALOG transport; gold stays off the wire.
- Engine rollback: turn off `CONTEXT_GRAPH_RETRIEVE`; sealed revisions remain readable via v2 resolve routes.
- C3 research HTTP/MCP stays dark until `CONTEXT_GRAPH_RESEARCH=1|true` (default off); create/list/get/checkpoint/reserve refuse fail-closed. Blank/whitespace/padded wait `subjectId`/`subjectRevisionId` never wake (incomplete_wake_subject_identity). Blank/whitespace/padded `scope.tenantId` never wakes when wait is set (incomplete_wake_tenant_identity). List is key-scoped only: blank/surrounding-padded client tenant overrides and listed `scope.tenantId` pads fail closed (`incomplete_list_tenant_identity`, backend #288). Surfaced or checkpointed `notes` with blank/surrounding-padded note id or ResearchScope fields (`tenantId`/`userId`/`dealId`/`sessionId`) fail closed (`incomplete_eligible_note_identity`, backend #297) — equal pads must not look like certified eligible memory. Blank/surrounding-padded `open_requirement_ids` / `progress.openRequirementIds` / `progress.failedRequirementIds` fail closed (`incomplete_loop_requirement_identity`, backend #304) — pads must not look like a certified loop stop. Blank/surrounding-padded EvidenceOperation `operation_id` / `root_operation_id` / `operation_ids` fail closed (`incomplete_operation_identity`); blank/padded `attempt_id` fails closed (`incomplete_attempt_identity`); blank/padded `record_operation_attempt.provider` → `incomplete_attempt_provider_identity`; blank/padded string `model` → `incomplete_attempt_model_identity`; blank/padded string `provider_idempotency_key` → `incomplete_attempt_provider_idempotency_identity`; blank/padded string `resolve_operation_attempt.failure_class` → `incomplete_attempt_failure_class_identity`; blank/padded `price.amount`/`currency`/`priceRevision` → `incomplete_attempt_price_identity`; blank/padded `consumer_kind` / `consumer_id` fail closed (`incomplete_consumer_identity`); blank/padded `open_operation_root` / `reserve_research_budget` / `reserve_operation` `idempotency_key` → `incomplete_operation_idempotency_identity`; blank/padded `kind` → `incomplete_operation_kind_identity` — pads must not trim-launder into certified I4 hits. W3 workflow path ids: blank/surrounding-padded `get_context_workflow.revision_id` / `run_saved_workflow.revision_id` → `incomplete_workflow_revision_identity`; blank/padded `run_saved_workflow.event_id` → `incomplete_workflow_event_identity`; blank/padded `get_workflow_run.run_id` → `incomplete_workflow_run_identity` — equal pads never trim-launder into certified workflow hits (#264/#279 honesty). W3 evaluation path ids: blank/padded `get_evaluation`/`compare_evaluations`/`get_evaluation_case` run ids → `incomplete_evaluation_run_identity`; blank/padded `case_id` → `incomplete_evaluation_case_identity` — equal pads never trim-launder into certified evaluation hits.
